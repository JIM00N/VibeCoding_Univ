# 브리프 ↔ PRD 정합성 점검 — hospital-care

> 목적: 원본 제품 브리프에서 PRD(+addendum)로 넘어오며 **조용히 빠지거나 약해진 것**, 특히 FR 리스트가 잘 잃어버리는 **정성적 의도(우선순위·리스크·"왜")** 를 잡아낸다.

## 전체 충실도 (한눈에)

전반적으로 **충실도 높음**. PRD는 브리프를 빠짐없이 확장했고, 오히려 가용성/충돌·walk-in·보안 posture를 더 촘촘히 정의했다. 브리프의 4개 MVP 흐름(역할선택→예약→진료기록→조회)과 4개 성공기준은 전부 PRD로 이관됐다.

빠진 것은 대부분 **기능이 아니라 정성적 맥락**이다: (1) 브리프의 "문제(왜)" 섹션이 PRD에 통째로 없음, (2) 정량 페인 미조사라는 범위 단서, (3) "진료과 전역코드 + N:M 중복제거" 설계 근거의 약화, (4) "의사는 진료 시 배정" 의도가 auto-assign으로 바뀌며 생긴 PRD 내부 불일치.

- **진짜 갭(우발적 누락/약화): 4건** (아래 G1~G4)
- 의도적 변경: 3건 (단일병원 · RLS-ON · 가용성+auto-assign+walk-in) — 전부 문서화됨
- 브리프 이후 추가: 아래 목록 참조

## 🚩 핵심 flag — "의사는 진료 시 배정" vs auto-assign-at-booking

**브리프 원문(해결책 step2):** "(담당 의사는 진료 시 배정 가능 → 예약의 의사는 선택)"
→ 의도: 의사는 **진료 시점에** 배정할 수 있으므로, **예약 시점엔 의사가 비어 있어도 됨**(선택). UJ-2 step3의 "직원이 확정하며 담당 의사(김민재)를 배정"이 이 "진료 시 배정"의 실현.

**PRD 새 모델(FR-6):** 의사 미선택 시 **예약 생성 그 순간** 진료과 내 빈 의사를 **자동 배정**. 배정 실패 시 예약 자체 거부.

**판정: 부분적 불일치 — 조용히 바뀌었다기보다 "의도적 변경 + PRD 내부 불일치".**
- 살아남은 것: "예약 시 의사 선택은 optional"(FR-6 "직접 고르거나 비워둘 수 있다") — 브리프 문구 유지 ✅
- **바뀐 것(의도적):** "비워둠 = 진료 시로 미룸"이 아니라 "비워둠 = 예약 시 즉시 auto-assign". 즉 **의사 배정 시점이 진료→예약으로 앞당겨짐**. `appointment.doctor_id`가 (auto-assign 성공 시) 항상 예약 시점에 채워져, addendum A3의 nullable 허용이 FR-6 경로에선 사실상 잉여가 됨.
- **PRD 내부 불일치(주의):** UJ-2 step3는 여전히 "직원이 확정하며 **담당 의사를 배정**"이라 서술 → 하지만 FR-6이 예약 시 이미 배정했다면, 이건 초기 배정이 아니라 **재배정(FR-7)** 이 되어야 논리가 맞음. 사용자 여정 서술과 기능 요구가 어긋남 → 아키텍처 전에 문구 정리 필요.

권고: FR-6/UJ-2에 "auto-assign된 의사는 직원이 확정 단계에서 변경 가능(FR-7 재배정)"을 한 줄 명시해 브리프의 "진료 시 배정" 의도를 흡수·복원할 것.

## 브리프 이후 추가된 것 (Added since brief)

브리프엔 없었고 PRD/addendum에서 새로 도입 — 대부분 의도적 강화:

- **🔁 단일 병원 전제** — 병원 선택 제거, 진료과만(§4, addendum A3).
- **🔁 RLS ON + 백엔드 경유 잠금** — 브리프의 "RLS OFF, 확장과제" 를 역전(NFR-4, addendum A1). 보안 강화.
- **➕ 가용성/충돌 규칙(FR-15)** — (의사, 시각) 슬롯 단위 충돌 차단. 브리프엔 개념 없음.
- **➕ 예약 시 의사 자동 배정(FR-6)** — 위 flag 참조.
- **➕ Walk-in 즉시 진료(FR-16)** — 예약 없이 빈 의사에게 즉시 진료·기록, 동일 슬롯 점유.
- **➕ 예약 상태머신 명시(FR-8)** — 대기→확정→완료/취소.
- **➕ 역-지표/Guardrail(§2)** — "넓이보다 한 줄기 관통 우선" 명문화(브리프 일정 우선순위를 지표로 승격).
- **➕ 세부 가정(§7)** — 신원선택 방식, 시드 규모(진료과당 의사 2+명), 슬롯 granularity, 취소=슬롯해제/완료=미래무관 등 오픈이슈.
- **➕ FR-5 환자 이름 검색** — 브리프엔 미언급된 조회 편의.

## 다운스트림 권고 (요약)

1. **G1/G2 복원:** PRD 또는 addendum에 짧은 "문제·전제" 문단 추가 — 정성적 "왜"와 "정량 페인 미조사" caveat를 남겨 과대해석 방지.
2. **G3 설명 보강:** 단일병원인데 `hospital_department`(N:M) 유지하는 이유를 addendum A3에 1줄(전역 진료과 코드 재사용/이력 스키마 안정).
3. **G4 정리:** FR-6 auto-assign과 UJ-2 "배정" 서술의 시점 불일치 해소(재배정 명시).
4. 참조데이터 "관리 옵션" 완전 제외가 의도인지 재확인(브리프는 열어뒀음).
