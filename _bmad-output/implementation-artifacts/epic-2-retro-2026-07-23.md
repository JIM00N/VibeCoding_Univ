**기술 준비 (3.1 create-story에 반영할 것)**
- **첫 다중 문장 트랜잭션:** INSERT `medical_record` + UPDATE `appointment`(확정→완료)가 같은 tx(AD-5). 현재 db 계층은 함수마다 자기 커넥션 → **db 함수 하나가 한 커넥션·한 트랜잭션으로 두 문장 실행**(또는 단일 CTE 문)으로 db 계층 안에서 해결. 아키텍처 리팩터 불필요.
- **AD-6 스냅샷 복사:** 기록의 과·의사는 작성 시점 값 복사 저장(라이브 조인 금지) — 서비스 로직.
- **medication refdata (3.2):** 약 선택용 `GET /medications`(doctors 미러) 필요 — 시드의 약 테이블·데이터 실측 선행.
- **부분 유니크 인덱스:** `uq_medical_record_appointment` 1.1 마이그레이션에 기존재 → ✅ 준비됨.
- **반복 행 폼(3.2):** 첫 동적 폼 UI(행 추가/삭제, UX-DR5) — 신규 패턴.
