# VibeCoding Univ

바이브 코딩(Vibe Coding) 학습을 위한 저장소입니다.

현재 진행 중인 프로젝트는 병원 진료관리 앱(hospital-care) — `frontend/`(Next.js) + `backend/`(FastAPI) + Supabase.

## 배포

- **앱(프런트, Vercel)**: https://vibe-coding-univ.vercel.app
- **API(백엔드, Railway)**: https://vibecodinguniv-production.up.railway.app ([/health](https://vibecodinguniv-production.up.railway.app/health))

- **처음 세팅한다면 → [docs/환경셋업.md](docs/환경셋업.md)** (준비물 · `.env` 만들기 · 실행 확인 · psql 없이 DB 만지기 · 자주 나는 오류)
